# 🛍️ Xhopii - Front-End E-Commerce

Interface Web responsiva inspirada em plataformas de e-commerce (Shopee), desenvolvida como requisito para o **Trabalho Prático 1** da disciplina de **Eletiva - Linguagem de Programação IV - INTERNET** — FATEC Presidente Prudente.

---

## 📌 Sobre o Projeto

O objetivo principal deste projeto foi construir a interface completa do front-end da plataforma **Xhopii**, priorizando fidelidade visual, estruturação semântica, regras de navegação entre telas e boas práticas no controle de versão.

---

## 🚀 Tecnologias Utilizadas

* **HTML5:** Estruturação semântica das páginas.
* **CSS3:** Estilização personalizada utilizando:
  * **Flexbox** para alinhamento e distribuição de componentes.
  * **CSS Grid Layout** para a organização de grids de produtos.
* **JavaScript (Vanilla DOM):** Manipulação dinâmica da interface (DOM) e seleção interativa de atributos de produtos.
* **Bootstrap:** Utilizado exclusivamente para a implementação do componente de **Carrossel** na Home Page.
* **Git & GitHub:** Versionamento de código.
